This repository contains two Embedded C programs demonstrating UART (Universal Asynchronous Receiver/Transmitter) communication using the PIC18F4520 microcontroller.
The first program continuously transmits the character 'A' through UART with a software delay. The second program receives serial data and retransmits the same data, demonstrating UART receive-and-echo functionality.
These programs provide a practical introduction to serial communication and UART register configuration in embedded systems.
